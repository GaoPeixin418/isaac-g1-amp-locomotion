# 开机器清单（立刻执行）

> 目标：两天内跑通 **Unitree G1 + AMP（Adversarial Motion Priors）拟人态走跑**，交付视频 + 代码仓库 + 一页技术报告。
> 环境安装要 1.5–2.5 小时且是后台跑的，**机器开得越早，训练时间越多**。

---

## 1. 机器规格（按优先级）

| 项 | 要求 | 说明 |
|---|---|---|
| **GPU** | **24GB 显存**（RTX 4090 / 3090 / A10 / A100） | AMP 需要 ≥2048 并行环境才收敛得快，24GB 是底线。8GB 卡只能开 256–512 env，两天内出不了好效果 |
| **系统** | Ubuntu 20.04 / 22.04（官方只测过这两个） | Isaac Sim 5.x 需要 **Python 3.11** |
| **磁盘** | **≥150 GB 可用**，且装在**数据盘** | isaacsim 完整装完 ~35 GB，加 Isaac Lab + 数据集 + 日志轻松破 80 GB。别装系统盘 |
| CPU / 内存 | 8 核+ / 32 GB+ | 4096 env 的物理步进吃 CPU |
| 持久化 | 数据盘重启不丢 | AutoDL 用 `/root/autodl-tmp`，9gpu 用 `/data` |

⚠️ **开机第一件事**：确认之前 Poppy 的 `/data`（或 autodl-tmp）还在不在。如果实例已彻底释放，`v8/v9` 权重可能没了——先别管，先开干，Poppy 的本地备份还在。

## 2. 网络预检（国内服务器的大坑，先花 2 分钟测）

登录机器后先跑这几条，哪个不通提前告诉我，我换方案：

```bash
# GitHub
timeout 20 git ls-remote https://github.com/isaac-sim/IsaacLab.git HEAD && echo "GitHub OK" || echo "GitHub FAIL"

# PyPI / NVIDIA 源
timeout 20 curl -sI https://pypi.nvidia.com | head -1
timeout 20 curl -sI https://pypi.org/simple/ | head -1

# HuggingFace（大概率不通，不通就用镜像）
timeout 20 curl -sI https://huggingface.co | head -1
timeout 20 curl -sI https://hf-mirror.com | head -1

# GitHub LFS（legged_lab 用它拉 G1 USD 和 motion data）
timeout 20 curl -sI https://github.com | head -1
```

**已知对策**：
- HuggingFace 不通 → 脚本里已设 `HF_ENDPOINT=https://hf-mirror.com`
- pip 慢 → 可选清华源 `-i https://pypi.tuna.tsinghua.edu.cn/simple`（但 isaacsim 必须走 `pypi.nvidia.com`，别混用）
- GitHub LFS 拉不动 → **降级方案**：G1 的 USD 用 Isaac Lab 自带的（`isaaclab_assets` 里有 Unitree G1），motion data 走 HF 镜像下载 CSV

## 3. 开机后按顺序跑（复制粘贴即可）

```bash
# --- 第 0 步：装到数据盘，别装系统盘 ---
export WORK=/root/autodl-tmp        # 9gpu 改成 /data
mkdir -p $WORK && cd $WORK
sudo apt update && sudo apt install -y git git-lfs cmake build-essential

# --- 第 1 步：拉取本项目脚本（把本地 setup/ 目录传上去，或直接 git clone 你的仓库）---
# 建议：先在本地 git init + push 到 GitHub，服务器上 git clone（SOUL.md 要求：代码必须进 git）

# --- 第 2 步：装 Isaac Sim 5.1 + Isaac Lab 2.3.2（后台跑，约 60-90 分钟）---
cd $WORK/g1-amp-locomotion
nohup bash setup/01_install_env.sh > $WORK/logs_01_env.log 2>&1 &

# 盯着进度
tail -f $WORK/logs_01_env.log
```

第 1 步跑完（日志出现 `=== ENV OK ===`）再跑第 2 步：

```bash
conda activate env_isaaclab
nohup bash setup/02_install_legged_lab.sh > $WORK/logs_02_leggedlab.log 2>&1 &
tail -f $WORK/logs_02_leggedlab.log
```

两条都跑完，把日志最后 30 行发我。
