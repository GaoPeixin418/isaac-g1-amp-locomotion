### 🏆 对照实验结论（2026-10-20 22:00，今晚最重要的一份数据）

**λ 三档消融 → 完整对照闭环**，详见 [AMP_vs_PPO对照实验.md](./AMP_vs_PPO对照实验.md)

| 判据 | AMP λ=0.5 | **PPO λ=1.0** | 纯风格 λ=0 |
|---|---|---|---|
| 支撑占比单调性 | **−0.94** | **+0.60** ❌ | −0.54 |
| 平均 CoT | **0.62** | **2.75**（4.4×） | 1.20 |
| 3.0 m/s 高速档 | ✅ 正常 | ❌ **采集失败** | ⚠️ 误差 2.20 |
| 与人类参照带偏差 | **0.062** | 0.259 | 0.339 |

**PPO 的失败模式**：低速档很准（误差 0.09）但走的是**高频小碎步**
（步频 2.12 Hz / 步长 0.74 m，人类同速是 ~0.98 Hz / 1.53 m），能耗 2.5 倍；
**2.0 m/s 以上直接不会跑**（支撑占比 0.95–0.99 = 脚黏地，步频 0.08–0.15 Hz）。

⚠️ 必须说明的边界：PPO 只训 2500 iter vs AMP 4000+，**训练步数不对等**。
可辩护的是 PPO 无判别器收敛更快、低速档任务指标已收敛（0.087–0.101），
所以低速档的步态/能耗对比公平，高速档崩溃部分是训练不足。

> 评估从 10 min 缩到 2 min 的原因：Kit 的 shader 缓存热了之后启动不再重新编译。
> 这让"多 checkpoint 阶梯扫描"从奢侈变成几乎免费——所以才补跑了第 6 项。

⚠️ 止损：λ=1.0 若 22:30 未跑完，取当时最新 checkpoint，不等跑满。
✅ 公平性已用 `diff` 验证：两次 run 的 `env.yaml` 只差 log_dir，`agent.yaml` 只差
`max_iterations` 与 `task_style_lerp` —— 其余（机器人、奖励、seed=42、域随机化）完全一致。
`08_train_resume.sh` 支持 `LERP=` 环境变量，无需改代码。

#### 🔑 找到 style 权重的旋钮（明早调参用）

`/data/legged_lab/source/.../amp/config/g1/agents/rsl_rl_ppo_cfg.py`：

```python
amp_discriminator=RslRlAmpCfg.AMPDiscriminatorCfg(
    hidden_dims=[1024, 512], activation="elu",
    style_reward_scale=2.0,      # 风格奖励的绝对缩放
    task_style_lerp=0.5,         # ← 任务 vs 风格 的插值系数，AMP 原文的核心权重
)
```

`task_style_lerp`（λ）含义 —— ⚠️ 2026-10-20 更正为：
**`r_final = λ·r_task + (1-λ)·r_style`，λ 是「任务」的权重**
（源码 `rsl_rl/rsl_rl/modules/amp.py:203`，初稿写反了方向，此处保留更正记录）
- λ↑ → 更看重任务：更稳、更跟得住速度，但退回「能走但僵硬」的老路（λ=1 即标准 PPO）
- λ↓ → 更看重风格：更像人，但跟不上速度指令（λ=0 即纯模仿）
- **面试价值**：做 λ = 0.0 / 0.5 / 1.0 三档消融，对比 duty-factor 曲线、速度跟踪误差与 CoT，
  三档分别对应「纯模仿 / AMP / 纯任务」，是能讲出道理的 ablation
  （比单纯「我调了参数」强得多）
