## 3. STAR 故事（面试最高分的一节，挑 2 个背熟）

> 面试官问"你怎么发现问题 / 怎么调的 / 遇到最大困难"，答这节。
> 每个故事都套 **S 情境 → T 任务 → A 动作 → R 结果 → 一条可复用规律**，
> 结尾都落在"我主动发现自己错了"，这是比"我调出了好指标"更值钱的叙事。

### ⭐ 故事 1｜连续斜坡：把"任意速度"从"坐实"退回"加限定"（推这个，最新最漂亮）

| | |
|---|---|
| **S** | 项目一直对外说 "0.5–3.0 m/s 全程响应速度指令"，证据是 11 档离散扫描 ρ=0.9983、MAE 0.082，看起来完美 |
| **T** | 11-20 只剩 2 小时开机窗口、不能重训，我想验一件事：离散档"钉死每个速度跑 1500 步"测的是"能不能到达这个速度"，没测"速度变化时跟不跟得上" |
| **A** | 设计**连续三角斜坡**指令 0.5→3.0→0.5 m/s（24 s / 1200 步）补测；逐帧比 cmd 与 v_act。中途 ρ 只有 0.872 还冒出 −2.08 的负速度，差点误判"策略失控"——**先查口径**：发现是启动前栽暂态 + episode timeout 在 step 999 全局 reset 的尖峰混进来了，剔掉前 2.5 s、把窗口截到 timeout 之前 |
| **R** | 干净结果 ρ=0.926、**最佳滞后 0.92 s**；把指令平移 0.92 s 后 ρ→0.963、MAE 减半 → 主要是**纯滞后不是失控**。恒速段 MAE 0.068 vs 变速段 0.315（**4.6 倍**），|dc/dt|>0.2 的帧占 77%。机制：训练时指令每 10 s 阶跃重采样，策略从没见过平滑斜坡 |
| **加一层对照** | 对 1599 用同脚本再采一份：训练量 1600→3000，滞后只从 1.00 s 降到 0.92 s（−8%），而同期高速掉速靠加训练量缓解了 57% → **两种病机制不同**：掉速是没收敛（训练量能治），滞后是训练指令分布（训练量治不了，要加 ramping 采样） |
| **规律** | **"离散扫描看不出的滞后，连续斜坡一测就现形"**；差分/统计前先确认样本时间连续、排除 reset 段与启动暂态 |
| **追问预案** | "为什么不早测？" → 因为默认评测协议就是定速档，是我想到部署时指令是连续变化的，才补了这个能证伪的实验。"怎么根治？" → 训练指令分布加 ramping 采样，不是部署端前馈 |

### ⭐ 故事 2｜"更像人"和"更跛"同时成立：把矛盾拆成两个物理量（科研味最浓）

| | |
|---|---|
| **S** | 项目所有"风格分"来自**自训练 AMP 判别器**，拿它给自生成数据打分 = 开卷考试，只能组内比、不能跨方法排名 |
| **T** | 想要一个**不依赖裁判**、能证伪的自然度证据；同时要解释一个怪现象：续训后姿态明显更像人，但用户肉眼看却更跛了 |
| **A** | 用 **MMD/KS** 直接比策略 rollout 的 29 维关节角分布 与 LAFAN1 重定向到 G1 的真人分布（30 pkl / 4703 帧），配 200 次置换检验。又踩一个坑：参考 30 clip **全是转弯/侧步/变速，没有匀速直走**，直接拿全参考比定速直走会把"动作模式不同"算成"不像人" → 改**速度匹配主口径**（只比 \|v\|∈[v±0.35] 的帧），只比关节角、不比速度时序 |
| **R** | 1599→2999：KS_leg −18.6%、MMD² **−59%**，11 档无一恶化；但同期 @1.0 legAI **34.8%→51.8%（恶化 +17）**。两者不矛盾：MMD/KS 测"像不像人"（整体关节角分布），legAI 测"跛不跛"（左右扭矩比）——**是两个物理量**，合起来指向策略用"分工式跛行"去拟合风格分布 |
| **规律** | **一个看似矛盾的结果，往往是把两个物理量混成一个指标了**；下一轮治跛行不能用整体风格指标验收，必须逐关节对称 |
| **追问预案** | "p=0.005 是不是说明显著不像人？" → **不能这么解读**，p 只说明两分布可区分，绝对量级（KS~0.2、MMD²~0.02）才是答案。"为什么不早用 MMD？" → 判别器开卷是慢慢意识到的公平性负债，补证据链这轮才还 |

### 故事 3｜跨速度平均陷阱：全档均值"改善"掩盖常速恶化

| | |
|---|---|
| **S** | v2.3 从 1600 续训到 3000，做**训练量严格对齐**的前后对比（项目第一次做到同口径、同 seed、同脚本） |
| **T** | 判断"续训到底有没有让机器人走得更好" |
| **A** | 不先看均值，**逐档拆开** 11 个速度档的 legAI 和速度误差 |
| **R** | 全档均值 52.6→45.5 看着像改善，其实是**被高速段改善 14–22pp 拉低的假象**；用户最关心的 @1.0 常速从 34.8%→**51.8%（+17 恶化）**。而速度跟踪是真改善（ρ 0.9922→0.9983、高速 \|err\| −57%）。结论：**续训解决了"跑不到目标速度"，没解决"走得对称"** |
| **规律** | **对称 / 风格类结论一律逐档看，绝不先平均再比**；这是"合成指标被反向抵消"的跨速度版本 |
| **追问预案** | "那到底该不该续训？" → 看目标：要速度跟踪就续，要对称性别续；`1600 最好、3000 回升`在 v1 和 v2.3 两次出现，说明是**后期任务奖励压过对称项**，不是权重不够，下一步要做防回升约束而不是再调权重 |

### 故事 4｜warmup 相变 + "站着别动"局部最优（回答"你怎么调的"）

| | |
|---|---|
| **S** | 治跛行改左右扭矩对称惩罚，v1→v2.3 调了四轮 |
| **T** | 让对称约束生效又不破坏"学会走路" |
| **A** | 三个无 warmup 对照组到 1200 iter 全部判死（不会走），warmup 版 800→1200 起飞 → 用**前 500 iter 从 0 线性升到满额**的 warmup。另一次把权重 −1.0→−2.0，训到 iter 1200 实测速度只有 0.07（没在走），用**排除法**定罪 |
| **R** | 相变从 v1 的 400→800 推迟到 v2.3 的 800→1200；"站着别动"的真凶是 **\|τ·ω\| 在不动时≈0，惩罚为零**，加强惩罚反而把"不动"变成局部最优。回退 −1.0 并加 **never-walked 早停** |
| **规律** | **加强一个惩罚项前先问"它的零点在哪"**——如果"什么都不做"就能让这项归零，加大权重一定把策略推向不动；风格/对称类权重要小步（±50% 内），翻倍必炸 |
| **追问预案** | "warmup 是不是你发明的？" → 不是，是常见的训练技巧，我的发现是**它在这个任务上决定了 motor primitive 能不能形成**，代价是相变推迟一个窗口（这是单 seed 观测，别吹成结论） |

### 故事 5｜duty 误诊被肉眼推翻（项目最经典的更正，10-27）

| | |
|---|---|
| **S** | finetune 后测"触地时长不对称 duty AI" 24.2%→0.3%，我宣布"跛行完全消除" |
| **T** | 用户看视频说"还是有跛行，而且蛮明显""比 lam050 里走得好的还差"——指标与观测矛盾 |

## 5. 诚实红线（写进任何对外材料前自查）

1. **纯仿真，未上真机**，不写 sim2real。
2. **"全向"只说"任意方向前进"**，侧移/后退/原地转向不可用。
3. **"任意速度"必须加限定**：静态定速精确、连续变速有 ~0.9 s 滞后。
4. **λ=0.5 是框架默认值**，只扫 3 档，不称最优；对抗学习管"风格信号从哪来"，不管"各占多少权重"。
5. **自训练判别器的风格分不能跨方法打分**（开卷考试）；无裁判 MMD/KS 也只组内可比。
6. **只有 `1599→2999` 这一份前后对比是硬的**；其余跨方法、跨采样口径比较都不成立。
7. 结论被推翻时**保留原文 + 加更正块**，不删旧结论。
8. 参考动作 26 段 vs 30 段、5 帧采样间隔、PD 增益具体值**没记全**，被追问说"配置里有，具体值我没记"，不现场编。

## 6. 30 秒口述稿（"你项目现在做到什么程度、还有什么问题"）

> 项目是用 AMP 让宇树 G1 在仿真里走出拟人步态，全程没上真机。当前最终模型能按
> 0.5–3.0 m/s 的速度指令走，静态定速跟得很准（相关系数 0.998）；我补了连续斜坡、
> 外力推和无裁判自然度三类证据，发现速度连续变化时会有约 0.9 秒滞后，定位到是训练指令
> 阶跃采样造成的，加训练量治不了。还有三件事没根治：常速下左右出力不对称约 52%、
> 步子偏碎偏短、侧移后退不可用——而且对称性是越训越差，1600 轮比 3000 轮还好。
> 我个人最大的产出其实不是这几个指标，是一整套评测方法：踩过十几次指标口径的坑，
> 每次结论被推翻我都保留原文加更正块，最近一次是主动撤回了"高速掉速是数据分布问题"
> 这个我自己写的推断。
