## 1. 实验设计

**唯一变量**：任务奖励里新增两项

| 新增项 | 权重 | 参数 | 参数来源 |
|---|---|---|---|
| `feet_clearance` | +1.0 | target_height 0.1, std 0.05, tanh_mult 2.0 | **照抄 legged_lab 自带 G1 flat 配置** |
| `air_time_variance_penalty` | −2.0 | — | GO2 官方 −1.0 翻倍（补 λ=0.5 的稀释） |

其余全部不变：同一套 AMP 配置、同一 seed、同一 4096 envs、同一参考动作。

**对照组（关键）**：旧 run 的 `model_2000.pt`，即**同为 2000 iter** 的无新奖励版本。
没有这一组，本节所有结论都会是错的。

## 2. 结果：一胜一负

### 2.1 目标达成（这是加这两项的目的）

| 指标 | 旧 model_4000（干净环境） | 新 sym1999 | 人类参照 |
|---|---|---|---|
| 抬升对称指数 SI_clear 均值 | 16.2% | **3.7%** | < 5% ✅ |
| SI_clear 最大 | 32.7% | **8.5%** | — |
| 左脚抬升更低的档数 | 6/6（方向一致） | **1/4** | — |
| 支撑对称指数 SI_stance | 5.6% | **3.3%** | < 5% ✅ |
| **25 s 累计横漂** | 0.27–1.07 m | **0.03–0.20 m** | — |

**侧漂假说被验证**：我之前推测「侧漂是左腿偏弱的下游症状」，治完对称性后侧漂自愈。
全程没有单独调过任何横向速度惩罚项——治根比治症状干净。

### 2.2 代价（这是没预料到的）

| 速度档 | 旧 run 2000 iter | 新 run 2000 iter | 差值 |
|---|---|---|---|
| 0.5 | 0.45 | 0.50 | +0.05 |
| 1.0 | 0.96 | 1.11 | +0.15 |
| 1.5 | 1.56 | 1.60 | +0.04 |
| 2.0 | 1.98 | **0.93** | **−1.05** |
| 2.5 | 2.44 | **−0.00** | **−2.44** |
| 3.0 | 2.97 | **−0.00** | **−2.97** |

**同为 2000 iter，旧模型高速档全部正常，新模型 2.0 m/s 以上完全崩塌。**
所以这不是「训练步数不够」——是新奖励抑制了高速行为。

> ⚠️ 如果只拿 1999 iter 的新模型去比 4000 iter 的旧模型，
> 会得出「再训训就好了」的错误结论，然后白烧几小时机时。
> **同 iter 对照是这类 ablation 的底线。**

## 3. 崩塌机制

### 3.1 是「站着不动」，不是「摔倒」

| 观测 | 2.5 m/s 档实测 | 说明 |
|---|---|---|
| vx 逐秒 | 0.02, −0.01, −0.01, … （15 秒恒定） | 不是摔倒后的抖动 |
| foot_z 摆幅 | L 0.03~0.05（2 cm） | 脚几乎没动 |
| 指令纯净度 | 99.9%（cmd_x ≡ 2.50） | 排除指令污染 |

**结论：策略主动选择了站立。**

### 3.2 为什么站立是最优解

```
termination_penalty = −50  →  经 λ=0.5 稀释后有效值 −25
```

- 2000 iter 时策略还不会跑 → 尝试 2.5 m/s 会摔倒 → 每次摔倒 −25
- 站着不动 → **永远不触发终止**，且 upright 姿态还能拿到不错的风格分
- 于是「站着不动」成为局部最优

**一般规律：终止惩罚量级越大，「什么都不做」这个吸引子就越强。**
这一条对所有 locomotion 任务都成立，不只是 AMP。

## 4. 为什么判断「继续训就能好」

### 4.1 速度上限随 iter 单调上升

| checkpoint | 可用速度档（稳态误差 < 0.25） |
|---|---|
| 1000 | 0.5, 1.0 |
| 1600 | 0.5, 1.0 |
| 1999 | 0.5, 1.0, **1.5** |

约每 1000 iter 上限提升 0.5 m/s。外推：

| iter | 预期上限 |
|---|---|
| 3000 | 2.0 |
| 4000 | 2.5 |
| 5000 | 3.0 |
| 6000 | 3.0+ |

### 4.2 训练指标在下降，不是在发散

`error_vel_xy`（迭代对齐，原始 AMP 是 5000 iter 的 run）：

| iter | 原始 AMP | 新 sym（阶段一） |
|---|---|---|
| 200 | 0.743 | 1.240 |
| 1000 | 0.725 | 1.709 |
| 1400 | 0.656 | 1.246 |
| 1800 | 0.647 | **0.903** |

原始 AMP 在 iter 600 也有 1.945 的尖峰，说明这个指标本身噪声很大。
新 run 末段已降到 0.90 且仍在下降 → **是慢，不是错**。

## 5. 决定

**不调权重，直接从 `model_1999` 续训到 6000。** 理由：

1. 趋势证据支持「继续训能覆盖 3.0 m/s」
2. 中途改权重会破坏单变量 ablation，之后再也无法说清是哪一项起了作用
3. 阶段一已经产出一个**可直接用的中间成果**：0.5–1.5 m/s 区间对称性好、几乎不漂

备选（若 6000 iter 后高速仍未恢复）：把 `air_time_variance` 从 −2.0 降到 −1.0 再训。
理由：从指标拆分看，治「瘸」的主力是 `feet_clearance`（SI_clear 16.2%→3.7%），
`air_time_variance` 贡献的是 SI_stance（本来就只有 5.6%，边际收益小），
而 −2.0 是我为了补 λ 稀释自己翻倍出来的，没有实测依据。

## 6. 尚未验证 / 诚实边界

1. **崩塌机制是假说。** 证据支持「站立而非摔倒」，但没直接验证「摔倒 → −25 惩罚」这个因果链。
   要坐实需要：读训练日志里的 `Episode_Terminated/*` 或把 termination_penalty 改小后重训。
2. **外推是线性外推**，只有 3 个数据点，n=3 不可靠。
3. **6000 iter 是新训练量**，与旧 run 的 5000 iter 不对等，最终对比时要主动说明。
4. 全程仿真，未上真机。
