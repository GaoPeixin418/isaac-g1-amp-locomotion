# G1 拟人态走跑控制：AMP 的消融与对照研究

> 仿真项目（Isaac Sim 5.1 + Isaac Lab 2.3.2），**未做 sim2real，不涉及真机**。
> 全部数字来自 `backup/eval_out/*.npz` 的确定性 rollout，可复现。

**一句话结论**：在 Unitree G1 上，只有把风格奖励与任务奖励按 λ=0.5 绑定，才能同时拿到
"像人""能听指令""省电"三件事。三个极端对照各缺一块，且每种缺失都能用机制解释。

---

## 1. 问题

手写奖励能写清"跟住速度""别摔倒""省电"，但写不清"步频和步长怎么配合""摆动腿走什么轨迹"。
纯 PPO 会找到满足所有手写项、但完全不像人的解——**高频小碎步**：稳、准，但丑且费劲。

## 2. 方法

AMP 不逐帧跟踪参考动作，而是训练判别器区分"策略生成的 4 帧动作片段"与"真人动捕的 4 帧片段"，
把判别输出当风格奖励：

```python
# 源码 rsl_rl/modules/amp.py:203
return λ * task_reward + (1 - λ) * style_reward
```

**λ 是任务权重，不是风格权重**（与直觉相反）。λ=1.0 即标准 PPO，λ=0 即纯模仿。

判别器输入是 **4 帧 × 61 维 = 角速度(3) + 关节角(29) + 关节速度(29)**，
**刻意不含世界坐标与根节点线速度** —— 否则策略会去学"在场地某个角落走路"。
这个设计有道理，但它埋下了本项目最重要的一个失败模式（见发现一）。

## 3. 实验设置

| 项 | 值 |
|---|---|
| 机器人 | Unitree G1，29 DOF，Isaac Sim 5.1 |
| 算法 | PPO（rsl_rl），4096 并行环境 |
| 参考数据 | **同一批 30 段 LAFAN1**（已 retarget 到 G1 29DOF，总时长 156 s，含走跑过渡） |
| 四组对照 | λ=1.0 纯 PPO（2500 iter）／λ=0.5 AMP（5000）／λ=0 纯风格（3000）／DeepMimic（3000） |
| 公平性 | 同机器人、同 15 项任务奖励、同 seed=42、同 4096 envs；**唯一变量是奖励来源**（已用 `diff` 实证） |
| 评估 | 6 速度档（0.5–3.0 m/s）× 1500 步 × 0.02 s，剔除前 5 s 启动段，关掉外部扰动 |

## 4. 结果

| 模型 | 步态形状（duty 秩相关，应≈−1） | 与人类参照带偏差 | 稳态速度误差 (m/s) | CoT | 高速档表现 |
|---|---|---|---|---|---|
| λ=1.0 纯 PPO | **+0.60** ❌ | 0.259 | 1.285 | 2.75 | 2.0 m/s 以上崩溃 |
| λ=0 纯风格 | −0.54 | 0.339 | 1.360 | 1.20 | 原地 0.1–0.2 m/s |
| DeepMimic | **−1.00** ✅ | — | 只达参考速度 48–77% | 2.86（低速） | 3.0 m/s 未采到 |
| **λ=0.5 AMP** | **−0.94** ✅ | **0.062** | **0.178** | **0.62** | 3.0 m/s 正常 |

PPO 的"丑"被量化为：步频 1.5–2.1 Hz（人类 2.2 倍）、步长 0.27–0.74 m（人类 48%）、
能耗 2.75（AMP 的 4.4 倍）。AMP 在 1.0 m/s 是 0.88 Hz / 1.07 m，落在人类量级内。

## 5. 三条关键发现

**发现一：风格奖励单独用会被 exploit。**
λ=0 时判别器给出 **0.979 的最高风格分**，但支撑占比 0.82–0.93（脚几乎不离地）、
步频 0.23–0.45 Hz、实际只前进 0.1–0.2 m/s。
因为判别器输入不含世界坐标与根线速度，**它看不见机器人有没有真的在往前走**——
原地摆出跑步姿势照样拿满分。**风格奖励必须与任务奖励绑定，这就是 λ 取 0.5 而不是 0 的原因。**

**发现二：DeepMimic 形状对，但没走到。**
它的 duty 曲线（−1.00）比 AMP（−0.94）还单调，光看形状会以为它更好。
但它只跑到参考速度的 48%–77%，根位置稳定落后 0.31 m。
机制：奖励是逐帧对参考帧取 exp 核，姿态摆对就有分；而"加速追上去"要额外出力，
会被能耗正则惩罚 → 收敛到**姿势对、位置慢慢掉队**的局部最优。
**逐帧相似度最大化 ≠ 轨迹整体复现。**

**发现三：λ=0.5 有明确代价。**
速度指令只给前进方向，侧向稳定靠任务奖励里的横向速度惩罚，
而 λ=0.5 意味着这项惩罚被风格奖励**稀释了一半**，残余侧向速度 0.13–0.19 m/s，
在 2.0 m/s 走跑过渡带最大（0.191 m/s）。**风格权重越高，任务侧的稳定约束就越弱**——
这是能讲出来的 trade-off，不是缺陷掩饰。

## 6. 模型选型

跑了 checkpoint 阶梯（1000/2000/3000/4000/4999），出现两条方向相反的曲线：

| 指标 | 走势 | 最优处 |
|---|---|---|
| 拟人偏差 | 0.079 → 0.077 → 0.065 → **0.062** → 0.069 | 4000 |
| 稳态速度误差 | 0.216 → **0.156** → 0.172 → 0.178 → 0.201 | 2000 |
| CoT | 0.72 → 0.62 → 0.67 → 0.62 → **0.60** | 4999 |

选 **amp_4000**：拟人偏差全程最优，速度跟踪 0.178 明显优于训练终点的 0.201，
CoT 与 amp_2000 持平。**它严格不劣于训练终点**，且理由讲得出因果
（3000 后拟人度进入平台、速度跟踪开始单调退化，故在 4000 early stop）。

## 7. 诚实边界

1. **单次评估，无多 seed 重复。** 0.062 与 0.069 是单点观测，差异不显著，诚实说法是"很接近，取综合最优"。
2. **训练步数不对等**：PPO 2500 / DeepMimic 3000 / AMP 4000–5000。可辩护点是前两者无对抗训练、收敛更快，
   且低速档任务指标已收敛；但**高速档的崩溃部分是"没学会"、部分是"训练不足"，不能全归因于方法差异**。
3. **30 段 clip 对 DeepMimic 是 harder setting**：它原生没有 skill selector，要凭观测区分几十条动作。
4. 人类参照值是典型量级参照，只用于判"数量级是否合理"；秩相关、速度误差、CoT 不依赖外部文献。
5. 侧向稳定性是速度代理指标，**不等于摔倒率**（评估脚本当时未存 base height 与姿态角）。
6. **纯仿真，未上真机。**
