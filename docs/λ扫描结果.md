## 为什么扫这个

`r = λ·r_task + (1−λ)·r_style`。λ=0.5 是 legged_lab 的框架默认值，**不是我们选的**。
端点已有实测（λ=0 站着不动、λ=1 纯 PPO），中间只有默认这一个点。

三臂之间**只有 λ 一个变量动**：同 seed、同 env 数、同 iter、同奖励表。

### 一个必须先说清的换算

`style_reward_scale = 2.0`，所以**有效**权重不是 λ 本身：

| λ | 有效 task 权重 | 有效 style 权重 | task : style |
|---|---|---|---|
| 0.25 | 0.25 | 0.75 × 2.0 = **1.50** | 1 : 6 |
| 0.50 | 0.50 | 0.50 × 2.0 = **1.00** | 1 : 2 |
| 0.75 | 0.75 | 0.25 × 2.0 = **0.50** | **1.5 : 1** |

**只有到 λ=0.75，任务奖励的权重才第一次超过风格奖励。**
之前我一直以为是 λ=0.5 时两者各占一半 —— 不对，0.5 时风格是任务的 **2 倍**。

## 结论

### 结论 1：λ=0.25 可以直接淘汰，而且是机制性淘汰

不是"训练不够"，是**风格权重压死了任务信号**（task:style = 1:6）。
表现在：所有高速档稳态误差都 >0.27，CoT 0.72 三臂最高，SI_clear 13.1%。
这和 λ=0 时"站着不动"是同一机制的弱版本 —— 沿着 λ 轴，0.25 已经离 0 太近了。

### 结论 2：对称性不用再单独治了，λ 高能带下去

λ 从 0.25 升到 0.75，SI_clear 从 13.1% 掉到 3.3%（**4 倍**），
而对称奖励在三臂里是**完全一样**的。

也就是说：**对称性主要卡在任务信号太弱，不全是缺专门的对称奖励项。**
之前给对称奖励记的功，有一部分应该记到 λ 上。
（前提是认同 1500 iter 这个短周期 —— 见结论 5 的边界。）

### 结论 3：2.5 m/s 是三臂共同的短板 —— 但它是共因而非随机

| λ | 2.5 档稳态误差 | 该档 SI_clear |
|---|---|---|
| 0.25 | 0.759 | 21.4%（最大） |
| 0.50 | 0.319 | 17.7%（最大） |
| 0.75 | 0.244 | 8.0% |

三臂都在 2.5 档最差，且 λ=0.75 把这一档的稳态误差从 0.319 压到 0.244。
**2.5 m/s 大概率是 LAFAN1 参考数据的分布边界附近** —— 人类数据里 walk 到 run
的过渡区覆盖最薄。这条我还没有直接验证（没去看 LAFAN1 的速度分布直方图），
目前是假说。

### 结论 4：预设决策规则失效了，我要说明白

扫描前定的规则是：**先用跟踪指标淘汰，合格者里取风格分最高。**

按这条规则，λ=0.5 和 0.75 都合格，该选 **λ=0.5**（风格分 0.721 vs 0.390）。

但实测数据显示：**风格分和任务完成度是负相关的**，它不是"合格后还能加的分"，
而是"为了拟人付出的代价"。把它当 tie-breaker，等于把待权衡的量当成了裁决人。

规则的漏洞在于我默认了两个轴可以独立优化，实测是帕累托前沿上的取舍。

### 结论 5：真正的取舍是"你要讲什么故事"

| 目标叙事 | 推荐 λ | 理由 |
|---|---|---|
| 拟人 / 对抗式风格学习 | **0.5** | 风格分 0.721，风格权重是任务 2 倍，AMP 味道最足 |
| 走得稳、快、对称 | **0.75** | 稳态误差 −10%、3.0 档 −50%、SI_clear −60%、人参照带偏差最小 |
| 能耗最省 | **0.5** | CoT 0.63 vs 0.67 |

两者都合格的理由是：**都不牺牲任务完成度**（稳态误差都 <0.15）。
所以这不是"能不能走"，而是"你希望别人盯着哪一点看"。

## 诚实边界（面试要主动说）

1. **三臂都是 1500 iter**，不是最终模型长度。排序结论可信，绝对值不能直接写进简历。
2. **单 seed**。三个 run 用同一个 seed 42 —— 这保证了"只有 λ 一个变量"，
   但也意味着**没有统计意义**，不能说"显著优于"。
3. λ=0.75 的风格分 0.390 是**最低的**，这是它真实的代价，不是测量误差。
4. 2.5 m/s 的分布边界假说是推断，未验证。
